Write python code to transform dot code into tikz code.
The structure of tikz code must be as following:

Predefined begin part
```
\begin{tikzpicture}[
    node distance=1.0cm and 1.0cm,
    box/.style={
      rectangle,
      draw,
      very thick,
      inner sep=3pt,
      font=\small,
      align=center
    },
    edge/.style={->, very thick, >={Latex[length=2.5mm]}}
  ]
```

list of nodes:
```
\node[box] (Node44) {$R10_{[x,\,x+8)}^{\texttt{0x20e648dc9a7f23f9}}$};

\node[box, below left=of Node44]  (Node45)
{$R02_{[x,\,x+8)}^{\texttt{0x20e648dccb5f722e}}$};

\node[box, below=of Node44]       (Node47)
{$R02_{[x,\,x+8)}^{\texttt{0x209548dccb5f722e}}$};

\node[box, below right=of Node44] (Node49)
{$R22_{[x+2,\,x+4)}^{\texttt{0xffffffffffff9a7f}}$};

\node[box, below=of Node45] (Node46)
{$R22_{[x+2,\,x+4)}^{\texttt{0xffffffffffffcb5f}}$};

\node[box, below=of Node47] (Node48)
{$R22_{[x+2,\,x+4)}^{\texttt{0xffffffffffffcb5f}}$};

\node[box, below=of Node49] (Node50)
{$R02_{[x,\,x+8)}^{\texttt{0x209548dccb5f722e}}$};

\node[box, right=of Node50] (Node51)
{$R02_{[x,\,x+8)}^{\texttt{0x20e648dccb5f722e}}$};
```

list of edges:
```

```

end:
```
\end{tikzpicture}
```

Mind, that positioning of nodes must be relative.
First draw node with no outcoming edges.
When all parent nodes are drawn below. Nodes on the same level are placed relatively to the nodes on the same level. 

For example draw parents for the given node A:
If there is one parent:
  draw B below A;
If there are two parents:
  draw B1 below A
  draw B2 right B1
If there are three parents:
  draw B1 below A
  draw B2 right A
  draw B3 left A
And so one...

Formats of nodes and edges are given in the example.
Also transform labels from dot file to math labels in tikz format: add `$` at the start and end of label.
Keep the same topology as in the original graph.

Usage:
```
python ./convert2tikz.py ./dir-with-dots --out-dir ./dir-with-tikz
```
For each dot input file there is a corresponding tikz file with the same name, different extension.

In `./dots` there is an example `dot` file, it the `tikz` there is an example of resulted `tikz` file.


```
Node B below A
Node B1 right B
Node C1 below B
Node C2 right C1
Node D1 below B1
```
Here node D1 overlaps with node C2.
Pick directions left/right to avoid overlapping.

Now adjust nodes coloring:
All nodes with no incoming edges are asigned with unique color.
All nodes with incoming edges accumulate colors of each parent.
For example:

```
Node A has color red
Node B has color blue
Node C is child of A and B, therefore, half of node C is red, half is blue.
Node D is child of C, therefore the same color as C
```
If there are N parents for node A, the node A inherits all N colors from parents.
For this case I do not have example, so implement mechanism of coloring.
