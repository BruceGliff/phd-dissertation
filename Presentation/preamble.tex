\begin{frame}
  \frametitle{Актуальность}
  Рост числа вычислительных ядер в~современных многопроцессорных
  системах сопровождается постоянным усложнением архитектуры подсистемы
  памяти, иерархии кэшей и~протоколов синхронизации. Нарушения
  спецификации модели памяти --- правил того, в~каком порядке результаты
  операций разных потоков становятся видимыми друг для друга, ---
  приводят к~трудно воспроизводимым сбоям. Поэтому верификация
  консистентности памяти остаётся одной из~самых сложных и~актуальных
  задач разработки таких систем.
\end{frame}

\begin{frame}
  \frametitle{Цели и~задачи}
  \begin{block}{Цель}
    Создание методов и~разработка алгоритмов анализа консистентности
    памяти при~исполнении многопоточных программ в~многопроцессорных
    системах с~учётом моделей памяти.
  \end{block}
  Необходимо решить следующие задачи:
  \begin{enumerate}
    \item сведение многопоточной программы к~частично упорядоченному
      множеству операций с~памятью;
    \item разработка алгоритмов построения линейных порядков частично
      упорядоченного множества с~учётом свойств эквивалентных
      перестановок;
    \item разработка структуры данных для~полного описания результатов
      исполнения (графа состояний программы);
    \item разработка алгоритмов верификации соответствия аппаратуры
      заявленной модели памяти.
  \end{enumerate}
\end{frame}

\note{
  Работа состоит из пяти глав.

  \medskip
  В первой главе анализируются современные подходы к~верификации
  подсистемы памяти с~учётом моделей памяти.

  Во второй главе рассматривается представление многопоточной программы
  в~виде частично упорядоченного множества операций с~памятью.

  Третья глава посвящена построению всех линейных порядков с~учётом
  зависимостей операций.

  В четвёртой главе предложена структура данных ``граф состояний''
  для компактного представления результатов исполнения.

  В пятой главе приведены результаты вычислительных экспериментов.
}
