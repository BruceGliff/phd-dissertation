\begin{frame}
  \frametitle{Положения, выносимые на защиту}
  \begin{enumerate}
    \item Математическая модель анализа многопоточной программы в~виде
      множеств~$P,D$: частичный порядок~$P$ задаёт ограничения на~
      допустимый порядок операций с~памятью, обусловленные моделью
      памяти, а~отношение~$D$ задаёт зависимости между операциями;
    \item Алгоритмы построения представителей классов эквивалентности
      допустимых линейных порядков; доказаны корректность, полнота
      и~отсутствие повторного построения представителей одного класса;
    \item Структура данных --- граф состояний (State~Graph) --- для
      компактного представления множества допустимых результатов
      исполнения, сохраняющая информацию, необходимую для анализа
      достижимых состояний и~переходов между ними;
    \item Алгоритмы проверки допустимости исполнения относительно
      заданной модели памяти, основанные на~анализе классов линейных
      порядков и~на~анализе графа состояний.
  \end{enumerate}
\end{frame}
\note{
  Проговариваются вслух положения, выносимые на защиту.
}

\note{
  Работа состоит из пяти глав.

  \medskip
  В первой главе анализируются современные подходы к~верификации
  подсистемы памяти с~учётом моделей памяти.

  Во второй главе рассматривается представление многопоточной программы
  в~виде частично упорядоченного множества операций с~памятью.

  Третья глава посвящена построению всех линейных порядков с~учётом
  зависимостей операций.

  В четвёртой главе предложена структура данных ``граф состояний''
  для компактного представления результатов исполнения.

  В пятой главе приведены результаты вычислительных экспериментов.
}
