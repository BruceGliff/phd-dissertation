\begin{frame}
  \frametitle{Актуальность}
  \begin{itemize}
    \item
      В современных многопроцессорных системах растёт число вычислительных ядер;
    \item
      усложняются архитектуры подсистемы памяти, иерархии кэшей и
      протоколов синхронизации;
    \item
      нарушения спецификации модели памяти проявляются недетерминированно;
    \item
      пространство возможных исполнений при этом растёт экспоненциально;
    \item
      существующие подходы либо ограничены малым числом операций и
      узким классом сценариев, либо требуют аппаратной интеграции в
      проверяемую систему.
  \end{itemize}

  \note{
    Рост числа вычислительных ядер в современных многопроцессорных системах
    сопровождается усложнением архитектуры подсистемы памяти, иерархии кэшей и
    протоколов синхронизации. При этом нарушения спецификации модели памяти не
    проявляются детерминированно: они возникают лишь в редких сочетаниях
    конкурирующих обращений и проявляются как трудно воспроизводимые ошибки.
    Пространство возможных исполнений при этом растёт экспоненциально с числом
    операций, что делает полный перебор непригодным для программ с большим
    числом обращений к памяти. Существующие подходы либо ограничены малым
    числом операций и узким классом сценариев, либо требуют аппаратной
    интеграции в проверяемую систему.

    Поэтому разработка эффективных методов и
    алгоритмов верификации консистентности памяти, не зависящих от деталей
    реализации и применимых к широкому спектру тестовых сценариев, остаётся
    одной из самых сложных и актуальных задач разработки таких систем.
  }

\end{frame}

\begin{frame}
  \frametitle{Цели и~задачи}
  \vspace{-10pt}
  \begin{block}{Цель}
    Создание методов и~разработка алгоритмов анализа консистентности
    памяти при~исполнении многопоточных программ в~многопроцессорных
    системах с~учётом моделей памяти.
  \end{block}
  Необходимо решить следующие \textcolor{accentBlue}{\textbf{задачи}}:
  \begin{enumerate}
    \item сведение многопоточной программы к частично упорядоченному
      множеству операций с памятью;
    \item разработка алгоритмов построения линейных порядков
      частично упорядоченного множества, учитывающих свойства
      эквивалентных перестановок;
    \item разработка структуры данных для полного описания результатов
      исполнения многопоточной программы (графа состояний программы);
    \item разработка алгоритмов верификации соответствия аппаратуры
      заявленной модели памяти на основе анализа результатов исполнения
      многопоточной программы.
  \end{enumerate}
\end{frame}

\note{
  Работа состоит из пяти глав.

  \medskip
  В первой главе анализируются современные подходы к~верификации
  подсистемы памяти с~учётом моделей памяти.

  Во второй главе рассматривается представление многопоточной программы
  в~виде частично упорядоченного множества операций с~памятью.

  Третья глава посвящена построению всех линейных порядков с~учётом
  зависимостей операций.

  В четвёртой главе предложена структура данных ``граф состояний''
  для компактного представления результатов исполнения.

  В пятой главе приведены результаты вычислительных экспериментов.
}
